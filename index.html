Browser-based processing is not a substitute for your organization's privacy and security requirements. Common questions

Does PDFify upload my selected PDF?

Supported document processing runs in your browser in this static version, and the site does not send selected files to a PDFify processing server. Your browser does download libraries from external CDNs; see the Privacy Policy for details.

Can PDFify convert scanned PDFs into text?

The PDF to Text tool extracts selectable text. Image-only scanned pages generally need OCR; the OCR tool recognizes English text and may not accurately interpret every scan, font, or layout.

Why are some conversion and password tools not shown?

Accurate Office-file conversion and PDF password encryption require capabilities not included in this static build. We prefer not to display controls that would claim to perform a task they cannot complete.

Is the output guaranteed to be perfect?

No. Results can vary with file structure, page size, fonts, image quality, and browser memory. Always review downloaded files before submitting or relying on them.

How to Use PDFify Online

This guide explains the basic workflow for the PDFify tools. Tool controls differ depending on the task, so read the instructions shown beneath each tool title before processing a document.

General workflow

  1. Open All PDF Tools and choose the task you need.
  2. Select the required file or files. For PDF-to-image and PDF-to-text tasks, choose a PDF. For JPG to PDF, choose JPG or PNG images.
  3. Review settings carefully. Page ranges use page numbers starting at 1. For reordering, enter each page exactly once.
  4. Select the processing button and wait for the status message. Large files can take longer and use considerable browser memory.
  5. Download the output and open it to verify that all pages, text and images are correct.

Merge PDF files

Choose Merge PDF and select two or more PDF files. The merge order follows the order in which the files appear in the selection. If your browser's file picker does not make the order clear, rename files with numeric prefixes before selecting them. Review the combined PDF after downloading.

Split, extract or remove pages

Use a comma-separated list such as 1,3,5 or a range such as 2-4. Split PDF packages selected pages as separate one-page PDFs in a ZIP. Extract Pages creates a PDF from only the specified pages. Remove Pages creates a new PDF containing all pages except the specified ones. You cannot remove every page from a document.

Reorder pages

For PDF Page Organizer, enter the complete new page sequence. For example, a four-page document can use 4,1,2,3 to move the final page to the front. Every page number must appear exactly once and the list must include the full document.

Convert PDF pages to images

PDF to PNG or PDF to JPG renders each page. The output for multi-page PDFs is packaged in a ZIP. Higher rendering scales create larger, sharper images but use more memory. If a large document fails, try a lower scale or split the document into smaller sections.

Extract text and OCR

PDF to Text works best when the PDF contains a selectable text layer. If the document was created by scanning paper, use OCR PDF instead. OCR renders each page and attempts to recognize English text. Recognition quality depends on scan resolution, contrast, skew, handwriting, columns, and fonts. Always proofread the downloaded text.

Compress PDF: understand the trade-off

The included compression method redraws PDF pages as images at a chosen JPEG quality. This can reduce size for image-heavy documents, but it can also make text unsearchable, remove interactive forms and cause quality loss. It may even increase the file size for some PDFs. Keep the original file and compare output size and readability.

Crop and resize pages

Crop margins are measured in PDF points, where 72 points equal one inch. The page-boundary preset changes page dimensions; it does not scale and reposition the existing page artwork to fit. Use a copy of the source document and inspect all pages before printing.

Text to PDF, PNG or JPG

Type or paste text, choose a format, and set readable font and background colours. Text exports can use multiple pages for PDF, while image exports produce a single image. Long text can result in a large image and may be subject to the tool's character limit.

File handling and privacy

Supported processing runs in your browser in this static version. The site does not upload selected documents to a dedicated PDFify processing server, but your browser loads third-party libraries from public CDNs. OCR loads its engine and English language data when invoked. Read the Privacy Policy before processing confidential files.

When a tool cannot complete a task

Encrypted files, malformed PDFs, unusual fonts, large scans, limited device memory, or unavailable network libraries can cause processing to fail. Password encryption/decryption and faithful Microsoft Office file conversion are not included in this version. Do not assume a downloaded file is correct without opening it and checking the result.

For common questions, visit the PDFify FAQ. To report a bug, use the Contact page.

Frequently Asked Questions

Are the PDF tools free?

All browser tools can be used without an account. Optional account sign-up is only for email-verified cloud notes and files, and works after the website operator configures Firebase services. Browser or device limits may affect very large documents.

Are my documents uploaded to PDFify?

In guest mode, supported processing happens in your browser. Files only go to cloud storage if you explicitly upload/save them through the optional account feature or enable auto-save. Account cloud storage requires Firebase to be configured. Your browser also downloads third-party libraries; see the Privacy Policy.

Can I convert a scanned PDF to text?

The PDF to Text tool extracts text already present in a PDF. For scanned images, use OCR PDF. OCR is imperfect and should be proofread.

Why does compression sometimes make the PDF blurry or larger?

The included compression approach converts pages to images and reassembles them into a PDF. Lower quality can make the file smaller but can reduce readability and remove the original selectable text and forms. Because some PDFs are already optimized, the output can sometimes be larger.

Can I convert Word, Excel or PowerPoint files?

Faithful Office-file rendering is not included in the current static version. Those options are not offered as working conversions.

Can I password-protect or unlock a PDF?

PDF password encryption and decryption are not included in this version. PDFify will not label an unencrypted output as password-protected.

Does the signature tool create a verified digital signature?

No. It creates a visible signature statement PDF. It does not provide cryptographic signing, identity verification, certificate validation, notarization or proof of authorization.

Why did processing fail?

Check that the source file opens normally, is not password-encrypted, and is not too large for the available memory. Ensure your browser can load the external JavaScript libraries. Try a smaller file to see if the problem is document-specific.

Which browsers are supported?

Use a modern, up-to-date browser with JavaScript enabled. Features can differ across browsers and mobile devices. Very large files are generally more reliable on devices with more available memory.

Can I use PDFify for confidential documents?

Evaluate your own privacy obligations before processing sensitive content. Although selected files are handled locally by supported tools, the page relies on third-party CDN resources and no website can guarantee security for every device or network.

How do I report a problem?

Email info@pdfify.online with the tool name, browser, approximate file size and error message. Do not email confidential document files or passwords.

What the website is for

The site focuses on everyday document workflows such as combining PDF files, splitting page ranges, changing page order, rotating pages, adding visible page numbers or text watermarks, converting PDF pages into images, extracting selectable text, and creating a PDF or image from text.

Privacy Policy

This policy explains how PDFify Online handles data in guest mode and in its optional account service. Features that require cloud services only work after the site operator has configured Firebase Authentication, Cloud Firestore, Cloud Storage and restrictive security rules. The website must not be treated as configured for account storage until those services are explicitly enabled.

Guest use and local processing

You can use the browser-based tools without creating an account. Supported document-processing operations run locally in your browser; ordinary file selection does not by itself upload the file to PDFify cloud storage. Your browser downloads required libraries from third-party content delivery networks.

Optional account information

If account services are configured and you choose to register, Firebase Authentication processes the full name you provide, email address, authentication identifiers and verification status. PDFify requires you to verify your email before cloud notes and file storage are available. Passwords are handled by Firebase Authentication and are not stored in PDFify documents.

Notes and files you choose to save

When you explicitly save a note, upload a file or enable the optional auto-save setting for generated downloads, the selected text or file is sent to the project's Firebase Cloud Firestore or Cloud Storage service and associated with your Firebase user ID. Saved notes and file metadata are restricted by the project's security rules so a signed-in user can access only their own records. Auto-save is off by default. Avoid uploading passwords or highly sensitive records. File storage availability and pricing depend on the Firebase/Google Cloud plan and actual usage.

You can delete individual saved notes and files from your account. The account interface also offers an account-deletion flow that attempts to remove that account's saved cloud records and files. For a deletion or privacy request that cannot be completed through the interface, contact info@pdfify.online.

The website loads some JavaScript and styling libraries from third-party content delivery networks. Your browser must contact those providers to download the files needed for tools to work. PDFify Online does not control those third-party services.
